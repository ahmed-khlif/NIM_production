# Coding Agent Instructions

Before coding: read README.md and every file in /docs, inspect the repository, package manifests, Prisma schema, migrations, environment config and tests. Preserve working functionality.

Every completed feature must include authorization, server validation, persistence, required history events, responsive UI, loading/error/empty states, tests and documentation updates.

Do not auto-continue to another major phase. At each phase end run lint, typecheck, tests and production build.

Never put critical business rules only in React, bypass guards, hard-delete audit history, attach operators permanently to machines, emit realtime events before commit, or silently resolve offline conflicts.
