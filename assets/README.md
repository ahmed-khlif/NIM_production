# NIM Assets

## Brand

- `brand/nim-logo.png` — official NIM logo supplied by the project owner. Do not redesign or distort it.

## Illustration usage

Use illustrations sparingly. The product is a minimalist industrial application, not an illustration-heavy marketing website.

Recommended mappings:

- `login-security.png` → login screen
- `production-in-progress.png` → production/operator contextual empty or onboarding state
- `machine-assignment.png` → assignment empty/help state
- `traceability-history.png` → traceability empty/help state
- `delayed-production.png` → delayed work state
- `production-completed.png` → production completion confirmation
- `machine-maintenance.png` → maintenance state
- `quality-inspection.png` → quality module
- `offline-sync.png` → offline/sync state
- `import-excel-csv.png` → file import
- `piece-empty-state.png` → empty pieces state
- `users-team.png` → user administration empty state
- `no-search-results.png` → no results
- `access-denied.png` → 403
- `server-error.png` → 500/server unavailable
- `empty-machine-queue.png` → operator with no assigned work
- `notifications-alert.png` → notification/alert empty or onboarding state
- `profile-security.png` → profile/password/security page
